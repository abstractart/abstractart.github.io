# Сайт-визитка на Astro

Статический сайт-визитка. Собирается [Astro](https://astro.build), деплоится на
GitHub Pages автоматически при каждом пуше в `main`.

## Локальная разработка

```bash
npm install     # один раз — установить зависимости
npm run dev     # запустить dev-сервер на http://localhost:4321
npm run build   # собрать статический сайт в папку dist/
npm run preview # посмотреть собранный сайт локально
```

## Как изменить контент

Весь текст сайта (имя, описание, навыки, контакты) находится в одном файле:

```
src/data/profile.ts
```

Отредактируйте значения — они автоматически появятся на странице. Код почти не
нужно трогать.

## Как добавить запись в блог

1. Создайте Markdown-файл в папке `src/content/blog/`, например
   `my-post.md` (имя файла станет адресом: `/my-post/`).
2. В начале файла укажите метаданные и текст:

   ```markdown
   ---
   title: 'Заголовок записи'
   description: 'Короткое описание для списка и соцсетей'
   pubDate: 2026-10-04
   ---

   Текст записи в Markdown...
   ```

3. Готово: запись появится в списке блога, на главной в блоке «Последние
   записи» и в RSS-ленте (`/rss.xml`).

Файлы, начинающиеся с `_`, считаются черновиками и не публикуются.

## Деплой на GitHub Pages

1. Создайте репозиторий на GitHub. Для адреса вида `https://username.github.io`
   назовите его `username.github.io` (тогда сайт ляжет в корень домена). Любое
   другое имя — сайт будет доступен по адресу
   `https://username.github.io/имя-репозитория/`.
2. В `astro.config.mjs` укажите `site` (ваш будущий адрес). Если репозиторий
   называется не `username.github.io`, раскомментируйте `base` и впишите имя
   репозитория.
3. Запушьте проект:

   ```bash
   git init
   git add .
   git commit -m "Первая версия сайта-визитки"
   git remote add origin git@github.com:USERNAME/REPO.git
   git branch -M main
   git push -u origin main
   ```

4. На GitHub откройте **Settings → Pages** и в качестве Source выберите
   **GitHub Actions**.

Готово: workflow `.github/workflows/deploy.yml` сам соберёт сайт и опубликует
его. Дальше каждое изменение достаточно пушить в `main` — деплой произойдёт
автоматически.

## Структура проекта

```
├── public/               # статика как есть (favicon)
├── src/
│   ├── components/       # шапка, подвал
│   ├── content/blog/     # ← ЗАПИСИ БЛОГА (Markdown)
│   ├── data/profile.ts   # ← контент страницы «Обо мне»
│   ├── layouts/          # html-каркас, мета-теги
│   ├── pages/            # страницы (главная = блог, /about, /rss.xml, 404)
│   └── styles/           # стили
└── .github/workflows/    # автодеплой на GitHub Pages
```

Структура сайта: главная страница (`/`) — это блог со списком записей,
страница визитки «Обо мне» доступна по адресу `/about`, каждая запись —
по адресу `/<имя-файла>/`.
