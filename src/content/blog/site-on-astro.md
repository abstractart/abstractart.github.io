Этот сайт собран на [Astro](https://astro.build) — фреймворке, который
специально заточен под контентные сайты. На выходе он выдаёт чистый HTML
почти без JavaScript, поэтому страницы грузятся мгновенно.

## Контент отдельно, код отдельно

Тексты блога не захардкожены в страницы. Каждая запись — Markdown-файл в
папке `src/content/blog/`, а метаданные описаны схемой:

```markdown
---
title: 'Заголовок записи'
description: 'Короткое описание для списка и соцсетей'
pubDate: 2026-09-18
---

Текст записи...
```

Astro читает эту папку при сборке, проверяет фронтматтер по схеме и
генерирует страницу для каждой записи.

## Деплой без рук

Пуш в ветку `main` запускает GitHub Actions: сборка и публикация на
GitHub Pages происходят автоматически. От идеи до опубликованной записи —
один коммит.
