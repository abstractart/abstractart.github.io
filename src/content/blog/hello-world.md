## Как это устроено

Каждая запись — обычный Markdown-файл. Никакой админки и базы данных не
нужно: написал файл, закоммитил — сайт собрался и опубликовался сам.

```bash
npm run dev      # локальная разработка
npm run build    # сборка статического сайта
```

Если хочется связаться или обсудить тему — контакты на главной странице.
